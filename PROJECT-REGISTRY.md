# Sky365 Project Registry

This registry tracks projects that are governed by the Sky365 Engineering Knowledge Base.

## Status model

- `candidate` — identified but not yet reviewed.
- `discovery` — current-state discovery is in progress.
- `documented` — As-Is documentation is available.
- `governed` — project follows SEKB standards.
- `paused` — intentionally inactive.
- `legacy` — maintained only for compatibility or historical value.
- `archived` — read-only.

## Project classifications

- Active Product
- Active Component
- Research
- Prototype
- Legacy
- Duplicate
- Archive Candidate
- Unknown
