# خارطة المنتج: الرئيسية والسوق

**الحالة:** PLANNED. هذه خارطة منتج عامة للنشر، وليست دليلًا على اكتمال المزايا.

## الرئيسية

1. Hero واضح يعرض هوية السوق الحالي وفئاته الأساسية.
2. بحث سريع يحتفظ بسياق السوق والتصنيف والمدينة.
3. أقسام موديولات تظهر فقط إن أعادها Marketplace API كمفعلة وقابلة للعرض في الرئيسية.
4. إشارات الثقة: مراجعة الإعلانات، التوثيق، والدفع عند توفره.
5. CTA واضح للتصفح أو تسجيل حساب Marketplace، دون خلطه بحساب إدارة Sky365.

## صفحة السوق

1. قائمة إعلانات قابلة للفرز والتصفية مع حالات loading/empty/error.
2. تصنيفات مرتبطة بالسوق الحالي فقط.
3. مسار تفاصيل إعلان يحتفظ بـ`marketplace` context.
4. بطاقات موحدة تدعم العربية، الجوال، والصور البديلة.
5. رحلة شراء أو تواصل تبنى على API المتاح؛ لا تستخدم بيانات أو صلاحيات مفترضة محليًا.

## مراحل التسليم

| المرحلة | الناتج | معيار القبول |
| --- | --- | --- |
| 1 | Shell موحد وثيمات الأسواق | روابط السوق لا تفقد السياق، RTL والجوال يعملان |
| 2 | بحث وتصنيفات وإعلانات | كل حالة API لها واجهة loading/error/empty |
| 3 | موديولات ديناميكية | الموديول لا يظهر إلا إن كان مفعلًا من API |
| 4 | تحويل وثقة | القياس والتحليلات والدفع بعد اعتماد عقود Backend |

## حدود واضحة

أي تغيير في الـAPI أو Seed أو صلاحيات Identity أو SQL يتطلب طلبًا منفصلًا إلى فريق Sky365 Backend.
