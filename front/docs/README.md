# فهرس توثيق Mawashigate

هذا المجلد هو بوابة التوثيق للمشروع. افتح [صفحة الفهرس HTML](index.html) محليًا أو انشرها كوثائق عامة. الوثائق التنفيذية الخاصة بالواجهة موجودة أيضًا في `apps/web/docs` لتبقى قريبة من مصدرها.

| الوثيقة | الوصف | الحالة |
| --- | --- | --- |
| [معمارية الواجهة والأسواق المتعددة](architecture/MULTI_MARKETPLACE_FRONTEND_AR.md) | الحدود، السياق، الثيمات، الموديولات، ومسارات الصفحة | VERIFIED/CODE-ONLY بحسب البند |
| [دليل التطوير والتشغيل والنشر](development/FRONTEND_DELIVERY_GUIDE_AR.md) | الأوامر، المتغيرات العامة، GitHub Actions، وضوابط التسليم | VERIFIED |
| [خارطة المنتج للرئيسية والسوق](product/HOME_AND_MARKET_ROADMAP_AR.md) | اتجاه تطوير عام ومراحل قابلة للقياس | PLANNED |

## قاعدة الأدلة

- **VERIFIED:** تأكد من الكود أو Build أو GitHub Actions.
- **CODE-ONLY:** موجود في المصدر، ولم يثبت في إنتاج أو UAT مصادق.
- **PLANNED:** قرار أو مرحلة مستقبلية، لا تعتبر منفذة.
- **UNRESOLVED:** يحتاج دليلًا من Backend أو Azure أو UAT.

> `apps/web/docs` يحتفظ بتقارير التطوير الداخلية القريبة من الكود. لا يُنسخ تلقائيًا إلى مستودع المعرفة العام؛ لا بد من مراجعة كل وثيقة قبل نشرها.
