المسار التشغيلي

النشر

GitHub Actions يبني dist/apps/web وينشره إلى Azure Static Web Apps. دمج main هو مسار الإنتاج.

معايير حالة الدليل

  • VERIFIED: دليل من كود أو Build أو GitHub Actions.
  • CODE-ONLY: موجود في المصدر، دون UAT مصادق.
  • PLANNED: قرار مستقبلي وليس ميزة منفذة.
  • UNRESOLVED: يحتاج دليلًا من Azure أو Backend أو UAT.
