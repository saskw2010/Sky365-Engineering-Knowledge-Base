# AGENTS.md

This project follows the Sky365 Engineering Knowledge Base.

## Start every task

1. Read this file, `README.md`, `PROJECT-STATUS.md`, `CHECKPOINT.md`, and `docs/INDEX.md`.
2. Inspect the relevant code, tests, schema, configuration, and deployment files.
3. Compare documented, implemented, and requested behavior.
4. Record assumptions, contradictions, unknowns, and risks.
5. Plan the smallest safe change.
6. Implement and verify.
7. Update project documentation and checkpoint.

## Existing project rule

Map the As-Is system before proposing broad redesign. Label information as verified, inferred, proposed, obsolete, or unknown.

## Safety

Do not change frameworks, databases, tenancy, public contracts, identity, or security boundaries without an ADR and explicit review.
