# Bootstrap a New Project

Read the Sky365 Engineering Knowledge Base and initialize this repository as a new governed project.

## Instructions

1. Do not begin production implementation yet.
2. Create the standard project documentation structure.
3. Define the problem, users, goals, non-goals, constraints, scope, and acceptance criteria.
4. Create the initial domain model, architecture, data model, API boundaries, security model, tenancy model where applicable, test strategy, deployment approach, risk register, project status, and checkpoint.
5. Clearly mark unknown and proposed information.
6. Produce Mermaid diagrams for system context and major flows.
7. Propose the smallest first vertical slice.
8. Stop after documentation and planning for review.
