# Implement with Documentation Sync

Read the Sky365 Engineering Knowledge Base, the target repository's `AGENTS.md`, project status, checkpoint, documentation index, and all documents relevant to the requested change.

Then:

1. Inspect the implementation and tests before editing.
2. Compare requested, documented, and current behavior.
3. Report contradictions, assumptions, scope, risks, and affected contracts.
4. Update the implementation plan.
5. Implement the smallest safe change.
6. Run relevant verification.
7. Update all affected documentation, project status, checkpoint, decisions, and release notes.
8. Summarize completed work, evidence, unverified areas, and remaining risks.

Do not perform unrelated refactoring. Do not change costly architectural decisions without an ADR and explicit review.
