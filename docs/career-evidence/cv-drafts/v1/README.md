# CV Drafts v1 — Evidence-Governed

This folder contains the first working set of evidence-governed CV variants derived from the fork-aware repository audit plus documented professional history.

## Files
1. `01-MASTER-CAREER-FACTS.md` — source-of-truth career record.
2. `02-PRINCIPAL-ENTERPRISE-SOLUTION-ARCHITECT.md` — enterprise architecture / ERP / SaaS / integration focus.
3. `03-PRINCIPAL-AI-DATA-SOLUTIONS-ARCHITECT.md` — LLM / RAG / Agentic AI / document intelligence focus.
4. `04-MICROSOFT-AI-CLOUD-TECHNICAL-SPECIALIST.md` — Azure + .NET + enterprise modernization + AI focus.
5. `05-ENGINEERING-PLATFORM-LEADERSHIP.md` — Head of Engineering / platform / product leadership focus.

## Governance
- Untouched forks are excluded from technology evidence.
- Repository counts are internal evidence metrics, not ATS marketing claims.
- Experimental/research evidence is never presented as production delivery.
- Career history and code evidence remain distinguishable.
- No CV variant should overwrite the Master Career Facts; targeted versions are derived from it.
